TabBar isolated wireframe · board 960×200 (tab strip 36 + context-menu annotation). Hub: prototypes index · shell: main-window.

State:
TabBar · modes: new | terminal | sftp（同一标签切换模式，不是另开标签）

Active tab mode drives content: terminal / sftp / quick-connect. Switch to SFTP / Terminal = 原标签改 mode（同 id，不新开标签）。 Open SFTP（Session 菜单）才可能新建独立 SFTP 标签。分屏见 split（每叶各自 TabBar）。

三种 mode — new（New Tab / QC）· terminal · sftp；共享同一套标签条、关闭、拖拽、分屏。
Switch — Terminal↔SFTP 是同一标签改 mode（保留 SSH transport）；不要画成两个并列标签互切。
session.icon — Terminal / SFTP 标签显示会话图标（与 panels/sessions 同套）；New Tab 用 +。mode chip（TERM/SFTP/NEW）仅本原型标明状态。
AI origin — MCP/AI 创建的连接在名称旁显示实心 AI 标志（用户创建的不显示）。见 Settings → MCP。
Inline rename — 右键 Rename Tab → 原地改名（图标与 mode / AI 标志保留）。Demo 态钉住输入；产品路径 Enter/blur 提交、Esc 取消。
