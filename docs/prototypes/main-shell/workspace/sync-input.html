Legend — N9 Input Sync
  • One group, no roles: every session whose sync switch is On joins the same group. There is no SRC/RCV role and no “pick targets” preset — input typed in any group member (in practice the focused session) is copied to the other group members.
  • Bidirectional: focusing another member and typing copies that input to the remaining members; the injected copy is never re-broadcast (no feedback loop).
  • Per-session switch: the pane/tab header switch adds or removes one session from the group; sessions that are Off are never written to. Disconnected sessions leave the group automatically.
  • Pause / Stop: Pause keeps the group but sends nothing; Stop clears the group. Banner shows an ON / PAUSED chip (yellow when broadcasting); status chip + menu keep the same actions.
  • Membership badge: tab/pane uses a sync icon (not the SYNC text label).
  • AI/MCP input opts out: when an AI/MCP client sends input, key or a command to a session, that session is switched Off automatically (it must not broadcast AI input) and a one-shot notice appears in the status chip.
  • No modal (D23): enabling sync never opens a KEYS / paste / Ctrl+C type-to-confirm dialog. Control keys are only flagged in the status chip.
  • Status chip: SYNC → n targets, where n counts the other group members relative to the focused session.
  • Destructive Stop: greyscale wireframe uses heavier border/weight on Stop (not color).
