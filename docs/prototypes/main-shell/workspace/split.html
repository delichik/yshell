分屏与标签的关系
  • 叶结构：每个 pane = 自己的 TabBar + 活动标签内容（Terminal / SFTP / New Tab）。不要画「一条全局 TabBar + 下面多分屏内容」。
  • mode：New Tab / Terminal / SFTP 都可进分屏；叶子数与 mode 无关。SFTP 是标签 mode，不是 dock 面板。
  • Switch：某叶内 Terminal↔SFTP 仍是原标签改 mode（见 tab-bar），不会因为分屏变成两个标签。
  • 上限：最多 4 叶；拖标签到 pane 边缘分屏；关叶内最后标签后合并相邻叶。
  • Balance Panes：同级 ratio → 50%。
