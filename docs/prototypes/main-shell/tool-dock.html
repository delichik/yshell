Legend — N3 stacks

The main window is not a fixed left sidebar plus right dock. Two independent vertical stacks flank a central workspace: Left stack | Workspace | Right stack. Dockable panels — Sessions, Tunnels, QuickCommands, Transfers — each have PanelPlacement: Left, Right, or Hidden. Defaults (Sessions left; Tunnels + QuickCommands right) are starting layout only, not locks.

Each stack is a column of PanelFrames: 32px header (title + ⋯ menu) and a content stub. A 4px dashed split handle sits between stacked panels. Header menu: Move to Left, Move to Right, Collapse, Hide (Move to current side disabled). Optional resize grips between stacks and workspace are visual-only here.

SFTP is not a ToolDock panel — file transfer UX uses tab-embedded SFTP; see sftp-panel and related SFTP prototypes, not this dock chrome.
