Prototype annotations

所有原型共用的注释格式与通用窗体分区。 页面专有交互再写本页字母角标；chrome / spacer / footer 不要在每个原型重复。 表单控件样式 / 动画见 forms（form.css）。 ← prototypes index

1. 标准格式

字母 + 间隔号 + 短名：

A · Short name

  • 窗内角标：.anno-tag / .tag，叠在分区右上角，不占布局。
  • 窗内叠加层：.anno-layer 固定为 position:absolute; inset:0; pointer-events:none；注释节点必须放这一层，不得进入菜单 / 表单 / pane / footer 的文档流。
  • 窗侧 callout：与角标同一字母与标题；放在产品几何外（不计入 720×580 / 560×400）。
  • 页底 / board 图例：同样用 A · Title 列表（.anno），无侧栏时用这个。
  • 字母从 A 起，只编本页特有分区；不要跳号，不要用 chrome/spacer/footer 占字母。
  • 蓝色小字 .anno-note：实现易漏点（焦点 / 互斥），不是分区字母；也只能放在叠加层或窗口外。

2. 通用分区（各页勿再注释）

标准工具窗示意（标题栏 / 内容 / spacer / 页脚）。下列含义全局成立：

Window title
Page-specific body (forms / lists) — annotate with A · B · …
  • Chrome 标题栏 + 仅关闭 ×（工具窗不要 _ / □）。Esc / × 与页脚 Cancel 或 Close 同路径。尺寸见 Theme token。
  • Spacer flex 余量顶开页脚；字段顶对齐，中间留空是预期，不是居中失败。
  • Footer 浏览型仅 Close；编辑型 Cancel | Save（或主操作）。禁止再叠一层窗级 Close。分隔线 + 右对齐按钮。
  • Chrome — ToolWindowChrome：标题文案可写主机/会话名；正文不要重复「Sign in to…」类抬头。
  • Spacer — 固定窗高时消化多余垂直空间；单字段页也会有大块空白。
  • Footer — 一窗一条提交栏；破坏性主按钮可标 critical，安全默认焦点在 Cancel。
  • 主壳 / 管理器宽窗同样：标题栏与底栏规则相同；左右栏内容用本页字母注，不要再标「Chrome」。

3. 本页该写什么

  • 只写与别页不同的分区：Method、错误条、清单/表单、空态、右键入口等。
  • 角标与 callout / .anno 列表一一对应；共用样式见 _anno.css。
  • 页头 meta / 页底 .anno-ref 只链规范页（annotations / forms），不要再复述 chrome/spacer/footer 或控件规则长句。
  • 产品规则（「管理」文案、Remember、行高等）写在 forms / 契约 / 本规则文件；不要塞进表单 hint 或角标正文。
  • 用户向 hint 可以有：只写非显而易见的产品行为；勿教 SSH 常识、勿复述标题/开关（见 forms）。
