Prototype annotations

通用注释只维护一份：样式 _anno.css， 切片 components/anno-*（iframe + query）。 功能页只写本页字母内容，禁止再抄 legend/callout CSS。 ← hub

1. 标准格式

字母 + 间隔号 + 短名： A · Short name

  • 窗内角标：.anno-tag — iframe anno-tag
  • 窗侧 callout：.callout — iframe anno-callout
  • 页底图例：.legend + .anno — iframe anno-legend
  • 字母从 A 起，只编本页特有分区；chrome/spacer/footer 不占字母。
  • .anno-note：实现提示，不占字母；只放叠加层或窗外。

2. 真源切片（iframe）

改 _anno.css 或这些文件，所有嵌入处一起变。

3. 与产品壳

Titlebar / body / spacer / footer 用 tool-window / _chrome.css，不要用注释字母去标通用壳。
