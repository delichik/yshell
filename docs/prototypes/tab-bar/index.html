TabBar isolated wireframe · board 960×200 (tab strip 36 + context-menu annotation). Hub: prototypes index · shell: main-window.

State:
TabBar
Tab context menu (right-click any tab): Rename Tab → inline input; Close · Close Others · Close Left · Close Right · Close All; Reconnect · Disconnect (session tabs only); Switch to SFTP / Switch to Terminal when the paired view exists. Double-click tab title → inline rename.
Inline rename
Active tab title becomes an in-place <input class="inline-rename"> (not a dialog). Renaming tab demo state pins the field: blur does not commit or dismiss — use Enter to apply or Esc to cancel. Product behavior otherwise: Enter or blur commits; Esc reverts. Badge inline rename marks demo/sticky mode. Context menu Rename Tab and double-click use the same control.
