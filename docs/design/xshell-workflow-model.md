# Xshell 类工作台操作模型

本文档用于约束 YShell 的工作台实现，避免把功能做成临时按钮或通用 shell 工具。当前阶段只把 SSH 作为主协议闭环；本地 Shell 仅用于开发和分屏占位验证，不进入远期协议扩展叙事。

## 1. 信息架构

YShell 主窗口按 Xshell 类桌面客户端组织为固定四层：

1. **菜单栏**：承载完整命令分级，使用“文件 / 编辑 / 查看 / 选项卡 / 窗口 / 工具 / 帮助”。
2. **常用工具栏**：只放高频命令，例如快速连接、分屏、广播输入和选项。
3. **会话工作区**：左侧会话管理器，右侧标签栏和终端窗格。标签栏管理会话维度，分屏只管理当前标签内的窗格。
4. **状态栏**：显示当前窗格状态、日志、广播输入状态和风险提示。

不得把核心操作散落成无上下文的随机按钮；新增能力必须先归入上述分级，再决定是否暴露到工具栏或上下文菜单。

## 2. 菜单分级基线

| 菜单 | 第一批命令 | 说明 |
| --- | --- | --- |
| 文件 | 新建会话 / 快速连接、新建本地 Shell、断开当前连接、导入会话、导出会话 | SSH 连接入口必须在文件菜单和工具栏同时可达。 |
| 编辑 | 复制、粘贴、查找、撰写栏 / 撰写窗格 | 当前未完成项必须禁用显示，不能伪装成已实现。 |
| 查看 | 会话管理器、工具栏、状态栏、全屏 | 控制界面区域可见性。 |
| 选项卡 | 新建 SSH 标签、重命名、锁定、关闭、关闭其他 | 标签命令管理整个 session tab。 |
| 窗口 | 垂直分割、水平分割、下一个窗格、上一个窗格、广播输入到当前标签 | 分屏和广播属于窗口/窗格层级，不属于会话树。 |
| 工具 | 用户密钥管理器、主机密钥管理器、日志管理器、选项 | 未完成管理器先禁用，避免占位通过验收。 |
| 帮助 | 关于 YShell | 保留产品信息入口。 |

## 3. 分屏操作逻辑

- 执行水平或垂直分割后，只在当前标签内新增窗格，不新开浏览器窗口，也不弹出临时 terminal。
- 新窗格先显示“选择连接来源”，用户可在窗格内选择 SSH 快速连接或本地 Shell。
- 分屏比例属于标签布局状态；调整后终端容器必须重新 fit，并通过后端 resize IPC 同步行列。
- 快捷键切换窗格后必须把 xterm 焦点移动到新的活动窗格，不能只是改变边框。

## 4. 广播输入逻辑

- 广播输入只作用于当前标签内被勾选的已连接窗格。
- 开启广播前至少需要两个目标；关闭后目标清空，输入只进入活动窗格。
- 多行粘贴和危险命令必须确认，确认内容需要包含目标数量和输入预览。
- 状态栏、工具栏和目标窗格必须同时显示广播状态，避免用户不知道自己处在广播模式。

## 5. 视觉与滚动约束

- 主窗口、会话管理器、标签栏、终端窗格必须统一深色主题，不允许出现黑色主题叠白色页面背景。
- 应用根节点固定为视口高度；只有会话树和 xterm viewport 可以滚动，工作台外层不得产生多重滚动条。
- 终端区域必须被限制在当前 pane 内，xterm 不得“弹出”或撑破布局。
