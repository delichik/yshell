# 阶段 2 闭环审计：SSH 与会话管理 MVP

本文记录阶段 2 与设计文档的逐项对齐结果。阶段边界以 `docs/design/roadmap.md` 的“阶段 2：SSH 与会话管理 MVP”为准；分屏、广播输入、会话日志、命令片段、SFTP、跳板机、代理、端口转发和团队/插件能力属于后续阶段，本轮不纳入遗留项。

## 1. 阶段 2 范围

阶段 2 必须闭环以下能力：

- 快速连接。
- 会话树。
- SSH 密码认证。
- SSH 私钥认证。
- SSH Agent 认证。
- 主机密钥校验。
- 会话保存、编辑、删除、复制。
- 配置导入导出。
- 凭据不以明文写入普通配置文件，导出默认不包含秘密内容。

## 2. 审计发现与处理结果

| 项目 | 审计发现 | 处理结果 |
| --- | --- | --- |
| SSH 连接 | 之前只创建 SSH 占位 runtime，无法连接远程主机。 | 改为通过系统 OpenSSH 客户端在 PTY 中启动真实交互式 SSH shell。 |
| SSH resize | 之前 SSH runtime resize 为 no-op。 | SSH 与本地终端共用 PTY master resize，窗口变化会同步到远端 shell。 |
| 密码认证 | 之前 UI 收集密码但后端不使用，形成误导。 | 密码认证改为 OpenSSH 终端内交互提示，前端不收集、不保存密码。 |
| 私钥认证 | 之前只保存私钥路径并显示占位结果。 | 启动 OpenSSH 时传入 `-i` 私钥路径，私钥口令由 OpenSSH/ssh-agent 交互处理。 |
| Agent 认证 | 之前只是认证方式枚举。 | 启动 OpenSSH publickey 认证并使用系统 SSH Agent 环境。 |
| 主机密钥校验 | 之前只有类型边界和失败提示。 | 将主机密钥策略映射到 OpenSSH `StrictHostKeyChecking=yes/ask/accept-new`，未知主机与变更提示由 OpenSSH 在终端内明确展示。 |
| 会话 CRUD | 之前前端入口与后端命令不完整。 | 保存、编辑、删除、复制均完成前后端闭环。 |
| 配置导入导出 | 之前只有类型或预览逻辑。 | Tauri 与预览模式均提供导入导出，导出/导入默认清理凭据引用。 |
| 连接失败 UX | 之前快速连接失败可能关闭表单且无明确状态。 | 失败时保留快速连接表单、创建失败状态标签页，并在状态栏展示错误。 |
| 导入失败 UX | 之前 JSON 解析失败会成为未处理异常。 | 导入错误进入状态栏提示，不破坏当前会话列表。 |
| 凭据安全 | 之前密码/口令字段短暂进入前端状态。 | 本阶段不持久化 SSH 密码或私钥口令；配置文件与导出包只保存非秘密连接参数。 |

## 3. 当前阶段不纳入遗留的后续能力

以下能力在设计文档中属于阶段 3 及以后，或产品长期目标，不作为阶段 2 未完成项：

- 分屏增强、广播输入、多行粘贴确认、快捷键自定义。
- 会话日志、命令片段、最近连接、收藏、会话模板、批量编辑。
- SFTP 文件面板、传输队列、代理、跳板机、端口转发、自动重连。
- 团队配置源、插件 API、审计日志增强、主题包生态。

## 4. 验收状态

阶段 2 的功能闭环基于系统 OpenSSH：只要目标平台安装可执行的 `ssh`/`ssh.exe` 并具备对应网络访问，YShell 可以从快速连接或保存会话打开真实 SSH 交互式 shell，并使用系统 OpenSSH 的密码提示、私钥、SSH Agent 和 known_hosts 校验能力。普通配置与导出包不保存 SSH 密码或私钥口令。
