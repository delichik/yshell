# YShell 设计文档索引

YShell 的目标是实现一个开源、跨平台、符合 Fluent Design 设计语言、并在操作习惯上接近 Xshell 的终端与远程会话客户端。当前文档用于在 `codex/design` 分支沉淀产品边界、交互逻辑、技术架构与迭代路线，作为后续 Tauri + xterm.js 工程实现的基准。

## 设计原则

1. **类 Xshell 的工作流**：优先复刻专业 SSH 客户端的会话树、快速连接、标签页、多会话、分屏、广播输入、日志与传输等高频工作方式。
2. **开源与透明**：协议实现、配置格式、密钥管理、日志路径和数据迁移策略应可审计、可替换。
3. **跨平台一致性**：Windows、Linux、macOS 采用同一套前端交互和核心业务模型，仅在系统集成层做差异化适配。
4. **Fluent Design**：使用层级、材质、动效、阴影、圆角、图标和响应式布局建立现代桌面应用体验，同时保持终端区域高可读性和低干扰。
5. **安全默认值**：阶段 2 不在普通配置中保存 SSH 密码或口令；后续保存凭据时进入系统安全存储；危险操作需要确认；配置导入导出避免泄露机密。

## 后续使用方式

- 新功能立项前，先在产品需求或交互设计中补充用户场景与验收标准。
- 技术实现前，对照技术架构文档确认模块归属、IPC 边界和安全策略。
- 每个里程碑结束时更新路线图状态，并将真实实现与设计差异记录为决策日志。
