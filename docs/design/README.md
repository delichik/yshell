# YShell 产品设计与验收标准索引

## 产品原则

1. **优先复刻 Xshell 的主工作流**：会话树、快速连接、标签页、多窗格、广播输入、日志、SFTP、隧道和密钥管理是核心能力，不是附加装饰。
2. **终端可用性高于视觉效果**：终端输入输出必须低延迟、不卡顿、不错行、不吞字符；所有 Fluent/现代 UI 效果不得影响终端性能。
3. **配置与凭据分离**：会话配置可导入导出，密码、私钥口令、代理密码必须进入系统安全存储或明确不保存。
4. **所有高风险操作显式确认**：广播输入、多行粘贴、删除会话、覆盖导入、主机密钥变更、批量操作和危险命令必须有清晰确认。
5. **设计即验收**：本目录中的验收条款优先级高于现有代码行为。现有实现不符合文档时，应修改实现而不是降低标准。
