# YShell 体验与交互设计

## 1. 总体体验目标

YShell 的交互应让熟悉 Xshell 的用户无需重新学习即可上手，同时通过 Fluent Design 提供更现代的桌面体验。核心体验关键词是：清晰、稳定、高效、低打扰、可键盘操作。

终端客户端的视觉设计不能喧宾夺主。Fluent Design 的材质、层级和动效主要用于导航、面板、弹窗和设置页；终端主体区域应保持高对比、低延迟和可读性优先。

## 2. 主窗口布局

推荐主窗口采用三栏结构：

```text
┌────────────────────────────────────────────────────────────┐
│ 标题栏 / 命令栏 / 全局搜索 / 窗口控制                      │
├──────────────┬─────────────────────────────────────────────┤
│ 会话侧边栏   │ 标签页栏                                    │
│              ├─────────────────────────────────────────────┤
│ - 会话树     │ 终端工作区                                  │
│ - 最近连接   │ - 单终端                                    │
│ - 标签过滤   │ - 横向/纵向分屏                             │
│              │ - 底部状态栏                                │
└──────────────┴─────────────────────────────────────────────┘
```

### 2.1 顶部区域

- 显示应用标题、当前工作区、全局搜索、快速连接入口、设置入口。
- Windows 与 Linux 使用自绘标题栏时，应保留原生窗口拖拽、最小化、最大化、关闭行为。
- macOS 保留系统交通灯按钮，菜单命令映射到系统菜单栏。

### 2.2 会话侧边栏

- 默认位于左侧，可折叠、调整宽度、隐藏。
- 包含会话树、最近连接、收藏、标签过滤和导入导出入口。
- 会话节点显示名称、连接状态、主机信息和可选图标。
- 右键菜单提供连接、在新标签打开、编辑、复制、删除、导出、打开文件传输等操作。

### 2.3 标签页栏

- 每个标签页代表一个终端工作区，可以包含一个或多个窗格。
- 标签显示会话名称、连接状态、活动标记、只读/锁定状态。
- 支持拖拽排序、关闭其他、关闭右侧、复制标签、重命名标签。

### 2.4 终端工作区

- 使用 xterm.js 作为唯一终端渲染核心。
- 终端窗格之间用轻量分隔条表示，可拖拽调整比例。
- 当前活动窗格边框或标题条需要有明确焦点状态。
- 失焦窗格降低强调，但不得影响文本可读性。

### 2.5 状态栏

状态栏展示当前连接信息和快捷状态：

- 连接状态：连接中、已连接、断开、重连中、认证失败。
- 主机、端口、用户名。
- 终端尺寸：列 x 行。
- 编码、换行、日志状态、广播输入状态。
- 延迟或最近心跳状态。

## 3. 会话创建与编辑

### 3.1 快速连接

快速连接面板字段：

- 协议：SSH、本地 Shell；后续可扩展串口、Telnet。
- 主机、端口、用户名。
- 认证方式：密码、私钥、Agent。
- 私钥路径、私钥口令。
- 代理/跳板机。
- 保存为会话复选框。

交互原则：

- 只填写主机时，自动使用默认端口 22 和当前系统用户名作为建议值。
- 连接失败后保留用户输入，允许修改后重试。
- 保存会话时要求填写名称；名称默认由 `user@host` 生成。

### 3.2 会话属性

会话属性采用分组表单：

1. 常规：名称、文件夹、标签、备注。
2. 连接：协议、主机、端口、用户名、超时、保活。
3. 认证：密码、私钥、Agent、键盘交互。
4. 代理：HTTP、SOCKS、跳板机链路。
5. 终端：终端类型、编码、启动命令、环境变量。
6. 外观：字体、字号、配色、光标、背景透明度。
7. 日志：自动日志、日志路径、命名模板。
8. 高级：端口转发、X11、压缩、兼容选项。

## 4. 标签页与分屏

### 4.1 标签页操作

- 双击会话节点：在新标签打开。
- 中键标签：关闭标签。
- 拖拽标签到窗口外：创建新窗口。
- 标签关闭前如存在活跃进程或连接，需要二次确认，可选择“不再提示”。

### 4.2 分屏操作

- 快捷键创建水平或垂直分屏。
- 新分屏默认复用当前会话连接参数重新连接，也可选择本地 Shell 或其他会话。
- 分屏布局保存为标签页内部布局，不影响会话定义。
- 支持同步输入到当前标签所有窗格或手动选择窗格。

### 4.3 广播输入

广播输入是高风险功能，必须可见且可控：

- 开启后状态栏与终端边框显示明显提示。
- 支持广播到当前标签页、当前窗口、选中会话组。
- 粘贴多行命令前必须确认。
- 可设置危险命令关键字提示，例如 `rm -rf`、`reboot`、`shutdown`。

## 5. 复制、粘贴与选择

- 鼠标拖选文本后默认不自动复制；可在设置中开启选择即复制。
- 右键默认弹出上下文菜单；可配置为直接粘贴。
- 粘贴多行内容时弹出确认，展示行数和前几行预览。
- 支持矩形选择、全选当前缓冲区、复制为纯文本、复制为 HTML。
- 终端搜索支持当前窗格、当前标签和全部活动会话范围。

## 6. 快捷键策略

快捷键要兼容 Xshell 用户习惯，同时避免与系统快捷键冲突。

| 功能 | 建议快捷键 | 说明 |
| --- | --- | --- |
| 快速连接 | Ctrl+N / Cmd+N | 打开快速连接面板。 |
| 新建本地终端 | Ctrl+Shift+N / Cmd+Shift+N | 打开默认本地 Shell。 |
| 关闭标签 | Ctrl+W / Cmd+W | 活跃进程存在时确认。 |
| 切换标签 | Ctrl+Tab / Ctrl+Shift+Tab | macOS 可映射 Cmd+Option+左右。 |
| 水平分屏 | Ctrl+Shift+H | 可配置。 |
| 垂直分屏 | Ctrl+Shift+V | 可配置。 |
| 全局搜索 | Ctrl+P / Cmd+P | 搜索会话和命令。 |
| 终端查找 | Ctrl+F / Cmd+F | 查找当前终端缓冲区。 |
| 广播输入 | Ctrl+Shift+B | 开关必须有明显状态反馈。 |
| 打开设置 | Ctrl+, / Cmd+, | 进入设置页。 |

## 7. Fluent Design 应用规范

### 7.1 颜色与主题

- 支持浅色、深色、跟随系统三种全局主题。
- 终端配色与应用主题分离，避免应用主题切换破坏终端可读性。
- 默认提供若干终端配色：Dark、Light、Solarized Dark、Solarized Light、Monokai、One Dark。

### 7.2 材质与层级

- 顶部栏、侧边栏、命令面板可使用半透明或类 Mica/Acrylic 的视觉效果。
- 弹窗和浮层使用清晰阴影与圆角，保证不同平台上视觉一致。
- 终端区域默认使用纯色背景；透明背景作为高级设置。

### 7.3 动效

- 面板展开、弹窗出现、标签切换可使用短时动效。
- 终端输入、滚动、光标闪烁不得因动效引入卡顿。
- 用户开启减少动态效果时，所有非必要动画应关闭。

## 8. 设置中心

设置中心分为：

- 常规：启动行为、更新、语言、确认提示。
- 终端：字体、字号、行高、光标、滚动缓冲。
- 主题：应用主题、终端配色、透明度。
- 快捷键：快捷键搜索、冲突提示、自定义导入导出。
- 连接：超时、保活、代理默认值、主机密钥策略。
- 安全：凭据存储、清除敏感数据、导出策略。
- 日志：默认路径、命名模板、敏感内容提示。

## 9. 错误与确认提示

- 连接失败：展示错误摘要、详细错误、重试、编辑配置、复制错误。
- 主机密钥未知：展示指纹、算法、主机、端口，用户可接受一次或永久保存。
- 主机密钥变化：必须高优先级警告，不允许静默继续。
- 关闭活跃连接：提示连接数量和会话名称。
- 粘贴多行命令：提示行数、字符数和风险说明。
