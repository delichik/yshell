# YShell 验收标准矩阵

## 1. 使用方式

本矩阵是功能验收和测试用例设计的来源。每个需求都应转换为自动化测试、手工测试或检查清单。实现方不得以“当前代码不支持”为理由降低验收标准。

优先级：

- **P0**：没有该项则产品不可用或存在安全风险，必须在首个可用版本完成。
- **P1**：专业 SSH 客户端核心体验，必须在公开 beta 前完成。
- **P2**：增强效率或团队能力，可分阶段交付。

状态定义：

- **通过**：Given/When/Then 全部满足，且跨平台矩阵无阻塞问题。
- **有条件通过**：仅非目标平台或明确依赖环境缺失，可记录限制。
- **失败**：功能缺失、交互不符、安全不符、错误不可恢复或数据丢失。

## 12. 发布门禁

首个可用版本必须满足：

- 所有 P0 通过。
- P1 中本地终端、SSH、会话管理、标签页、日志至少通过 90%。
- 明文凭据扫描通过。
- Windows、macOS、Linux 均完成冒烟测试。
- 连续 1 小时 SSH 会话和本地终端无崩溃、无不可恢复卡死。
